Upcoming events

This page is a Django TemplateView whose template extends a base template, the traditional way. It is not a Page. The list below is an EventList widget the view rendered with widget.render(request) and put in the template's context, and each card keeps its own "Show details" script.

render() runs from sync code with no event loop, so the widget queries with the plain sync ORM. It needs no request either. Two more places a widget fits:

  • Email: every email is an EmailDocument widget, a whole HTML document with its head, header and footer, holding the email's own part as a child widget, rendered with render() and no request. python manage.py send_event_digest --to you@example.com and send_event_reminder print one each to the console.
  • An admin tool: the events tool in the admin is a custom admin view, beside the event admin, whose template extends the admin's own and holds a widget's HTML. Log in as admin, password try-the-widgets.
