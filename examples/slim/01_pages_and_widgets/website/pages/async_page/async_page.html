Slow calls, together

Slow calls, one after another

Each SlowQueryCard awaits its own call in its own set_context(), and the library finishes one widget's set_context() before starting the next. When several widgets need slow data, fetch it together in their parent and pass it down. SlowQueryCard also renders its base class's template, query_card.html, found beside the base class's module.

Gathering speeds up calls to other services. It doesn't speed up database queries: Django's async ORM runs every query on one shared thread, so they still run one at a time.
