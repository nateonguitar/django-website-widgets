Server-rendered widget from an endpoint

Tip 0 below was rendered as part of this page. The button asks GET {% url "website_widgets_example_api_tip" %}?number=1, then 2, and so on. That async endpoint awaits a mock database call, then renders an TipCard for that number on the server with await widget.render__standalone(request) and returns its HTML in JSON. The page adds it under the others, the way an infinite scroller or a "load more" button would. Both come from the same widget and template.

The button is disabled while the request is in flight, so a double click can't load the same tip twice.
