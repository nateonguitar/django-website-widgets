django-website-widgets examples

Every page here is rendered on the server, so its content, title and description are in the HTML before any JavaScript runs. That's what search engines index and what ad networks read. JavaScript is then added where it helps, calling JSON endpoints instead of submitting forms.

Each app below has its own base page and stylesheet, so each looks different.
