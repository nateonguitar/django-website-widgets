Unwrapped Page

This page uses base_unwrapped.html — a minimal base template with no header, navigation, or footer.

When to use unwrapped pages:

  • Login / Signup pages — focused UI without distractions
  • Error pages (404, 500) — simple error display
  • Print-friendly views — clean output for printing
  • Embedded content — pages loaded in iframes
  • Landing pages — custom layouts that don't fit the app shell
