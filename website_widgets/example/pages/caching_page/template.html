HTTP Caching Example

Demonstrating ETag and Last-Modified headers

This page uses ExamplePageComplex which provides:
  • ETag generation from timestamp + path + user
  • Last-Modified headers
  • 304 Not Modified responses for conditional requests
  • Canonical URL generation (strips tracking params)

How to test:

  1. Open browser DevTools → Network tab
  2. Reload this page
  3. Check the response headers for ETag and Last-Modified
  4. Reload again - browser sends If-None-Match / If-Modified-Since
  5. Server responds with 304 Not Modified (no body)
